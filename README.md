# Rekrypt

Rekrypt es una aplicación web que permite transformar cadenas de texto aplicando múltiples codificadores y algoritmos de hashing de manera secuencial. Dependiendo del orden en el que se seleccionan los métodos, el resultado final cambiará, permitiendo múltiples combinaciones.

## 🚀 Características

- Compatible con algoritmos como SHA-1, SHA-256, SHA-384, SHA-512, Blake2, MD5 y más.
- Interfaz intuitiva y fácil de usar.
- Transformaciones en tiempo real con vista previa de los resultados.
